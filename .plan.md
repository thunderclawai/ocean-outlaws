# Plan: Rework merchants: ambient world spawns, not combat wave enemies

## Issue
#152 — Merchants block combat wave completion because they flee and can't be caught; rework them as ambient world entities independent of wave state.

## Analysis

**Current state:** PR #168 already merged the full implementation into `main`. All acceptance criteria are satisfied by the existing code. This plan documents the implementation for reference and verification.

### Key files and how things work now:

- **`merchant.js`** (created by #168) — Standalone ambient merchant spawn system. Uses a timer-based spawner (`SPAWN_INTERVAL_BASE = 25s`, scales down with zone difficulty to `SPAWN_INTERVAL_MIN = 12s`). Merchants sail trade routes from one map edge to the opposite. 20% convoy chance spawns 2-3 merchants + 1 navy escort. Max 6 concurrent ambient merchants. Merchants despawn after 120s or when off-map.

- **`wave.js`** — `FACTION_ROTATION` is `["pirate", "navy", "pirate", "navy", ...]` (8 entries, no merchants). `buildWaveConfigs()` only produces pirate/navy waves.

- **`mapData.js`** — Zone-specific `FACTION_ROTATION` is also pirate/navy only. `buildZoneWaveConfigs()` uses this rotation.

- **`main.js:buildNodeWaveConfigs()`** (line 832) — Voyage chart node configs also use `["pirate", "navy"]` only. The `merchant_chase` node type still exists but reduces wave count/enemies (easier combat with ambient merchants nearby).

- **`enemy.js`** — `spawnAmbientEnemy()` (line 331) creates enemies outside the wave gate with `ambient: true` flag. Merchant faction AI (line 441): ambient unattacked merchants follow trade route; attacked merchants flee at `fleeSpeed`. Convoy aggro propagation via `convoyId` (line 775).

- **`main.js` line 1324** — Wave alive count excludes `ambient` enemies: `if (enemyMgr.enemies[i].alive && !enemyMgr.enemies[i].ambient)`. This ensures merchants never block wave completion.

- **`main.js` line 140-144** — Death callback: merchants get double pickups (2× `spawnPickup`) plus `FACTIONS.merchant.goldMult = 3.0` gold multiplier.

### Speed constants (merchant.js):
- `SPEED_RATIO_MIN = 0.5` / `SPEED_RATIO_MAX = 0.7` — cruise speed is 50-70% of player max
- `FLEE_SPEED_RATIO = 0.85` — flee speed is 85% of player max (always catchable)
- `SPEED_FLOOR = 4` — minimum speed for slow-ship-class encounters
