# Plan: Bug: bosses never spawn — wave configs missing boss assignments

## Issue
#153 — `buildWaveConfigs()` never set `.boss` on any wave config, so bosses could not spawn in default/multiplayer combat. The core fix was merged to main via PR #161 (commit a9a0be2), but two acceptance criteria gaps remain: boss damage does not scale with difficulty, and a hardcoded constant in the node-combat boss spawn path produces incorrect difficulty for non-standard chart sizes.

## Analysis

### What PR #161 already fixed (on main)
- `buildWaveConfigs(baseDifficulty)` now sets `cfg.boss = "battleship"` on wave 5 (mini-boss) and an escalated boss on wave 10 (carrier/kraken depending on difficulty)
- `createWaveManager` and `resetWaveManager` accept a `difficulty` parameter
- `startMultiplayerCombat` passes `difficulty=1`
- Boss difficulty fallback in the spawn handler uses `waveMgr.currentConfig.bossDifficulty`

### Three combat paths — all now assign bosses correctly
1. **Zone combat** (`buildZoneWaveConfigs` in `mapData.js:200-219`): boss on final wave from zone definition — was already working
2. **Run/node combat** (`buildNodeWaveConfigs` in `main.js:823-851`): boss on final wave of boss-type nodes — was already working
3. **Default/multiplayer** (`buildWaveConfigs` in `wave.js:23-51`): boss on waves 5 and 10 — **this was the broken path, now fixed**

### Remaining gaps

**Gap 1 — Boss damage does not scale with difficulty**
Acceptance criterion: *"Boss HP/damage scales with wave difficulty multipliers"*
- Boss HP scales correctly: `createBoss` (`boss.js:122`) uses `1 + (zoneDifficulty - 1) * 0.2`
- Boss projectile damage is hardcoded to 2 (`boss.js:446`)
- Boss tentacle damage is hardcoded to 3 (`boss.js:534`)
- Neither adjusts based on `zoneDifficulty` — a difficulty-6 boss does the same raw damage as difficulty-1

**Gap 2 — Node-combat boss difficulty uses hardcoded divisor**
In the boss spawn handler (`main.js:1333`), the run/node difficulty is calculated as:
```js
1 + Math.floor(currentNode.col * 5 / Math.max(1, 6))
```
The hardcoded `6` should be `activeChart.columns - 1` (matching how `buildNodeWaveConfigs` at `main.js:844` and terrain difficulty at `main.js:865` calculate it). For charts with more or fewer than 7 columns, boss difficulty will be wrong.

## Changes

### game/js/boss.js (modify)

- **`createBoss` (line 108-150)**: Store `damageMult` on the boss state object, computed as `1 + (zoneDifficulty - 1) * 0.15` (15% per difficulty tier, paralleling the 20% HP scale). Add it to the return object alongside existing fields.
- **`updateBossProjectiles` (line 446)**: Replace hardcoded `2` with `2 * boss.damageMult` so projectile damage scales:
  ```
  var dmg = Math.max(0.2, 2 * boss.damageMult * (1 - (enemyMgr.playerArmor || 0)));
  ```
- **`updateTentacleAttacks` (line 534)**: Replace hardcoded `3` with `3 * boss.damageMult` so tentacle damage scales:
  ```
  var dmg2 = Math.max(0.3, 3 * boss.damageMult * (1 - (enemyMgr.playerArmor || 0)));
  ```

### game/js/main.js (modify)

- **Boss spawn handler (line 1333)**: Replace hardcoded `6` with `(activeChart ? activeChart.columns - 1 : 6)` so node-combat boss difficulty uses the actual chart size:
  ```
  (currentNode ? 1 + Math.floor(currentNode.col * 5 / Math.max(1, activeChart ? activeChart.columns - 1 : 6)) :
  ```

## Order of Operations
1. Add `damageMult` field to boss state in `createBoss` (`boss.js`)
2. Update projectile damage calc in `updateBossProjectiles` to use `boss.damageMult` (`boss.js`)
3. Update tentacle damage calc in `updateTentacleAttacks` to use `boss.damageMult` (`boss.js`)
4. Fix node-combat boss difficulty divisor in spawn handler (`main.js`)
5. Manual playtest: verify bosses spawn on waves 5 and 10, damage feels harder at higher zones

## Testing
- Start a default/multiplayer game → verify battleship mini-boss spawns on wave 5 with reduced enemy count
- Survive to wave 10 → verify escalated boss (carrier at difficulty 1) spawns
- Start zone combat at Iron Strait (difficulty 2) → verify battleship spawns on final wave with slightly higher damage than Shallow Cove baseline
- Start zone combat at Black Trench (difficulty 5) → verify kraken spawns with noticeably higher damage (~1.6x base)
- Run mode: navigate to a boss node at various column positions → verify correct boss type and difficulty
- Verify boss HUD shows on spawn, loot drops on defeat, zone/run progresses after victory
- Edge case: difficulty 1 should produce `damageMult = 1.0` (no change from current behavior)

## Risks
- Damage scaling could make high-difficulty bosses too punishing if the multiplier is too aggressive. The 15% per tier is conservative (difficulty 6 = 1.75x damage). If playtesting shows issues, the coefficient can be adjusted.
- The `activeChart` variable could be null outside run mode. The fallback `activeChart ? activeChart.columns - 1 : 6` handles this safely.
- Boss damage changes affect multiplayer balance — since both players see the same boss state and damage is computed locally, the scaling will be consistent across clients.
